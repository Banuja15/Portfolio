RAG-Based Document Chatbot

Built a document question-answering application that processes PDF, TXT, and Markdown files. Semantic similarity scores help rank retrieved chunks by relevance, so the LLM receives more relevant context for accurate, context-aware responses.

PythonStreamlitOllamaGemmaBAAI-BGE
GitHub ↗
How it works

Documents are processed into text and represented as embeddings. Retrieved chunks are evaluated using semantic similarity scores to identify and prioritize context that best matches the user’s question. The relevant context is passed to Gemma through Ollama to generate a grounded response. The interface is built with Streamlit.

Core concepts

Document ingestion · Embeddings · Semantic similarity scoring · Relevance-based retrieval · Context-grounded generation.
