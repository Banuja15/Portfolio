# Banuja R. — Portfolio

A responsive, interactive single-page portfolio built with HTML, CSS, and JavaScript.

## Run locally
1. Keep `index.html` and the `assets` folder together.
2. Place your actual resume PDF at `assets/resume.pdf`.
3. Open `index.html` in a browser, or run a local server:
   - Python: `python -m http.server 8000`
   - Visit `http://localhost:8000`

## Deploy
Upload the folder to GitHub and import the repository into Netlify or Vercel, or deploy it with GitHub Pages.

## Before sharing
- Replace generic GitHub profile links on project cards with exact repository URLs.
- Confirm project descriptions and skills are accurate.
- Add `assets/resume.pdf` (the download buttons point to this file).
